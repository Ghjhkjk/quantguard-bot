🚧 功能開發中（Security & Architecture Review）

個人專屬自動化版 — 雲端金鑰安全託管規劃中

目前開放：官方實盤數據監控 ＆ 免費模擬沙盒體驗

為確保一般使用者的交易所 API 金鑰與資金安全，在「端對端加密託管」與「異常下單熔斷防護」尚未完成完整壓力測試前，本平台暫不開放外部使用者直接輸入真實 API 金鑰。您目前可透過上方的「免費模擬沙盒」零風險體驗完整策略與帳務勾稽功能。

1. 零私鑰曝險原則
開發中的個人版將強制限制 API 僅需開啟「交易權限」、嚴格禁止「提幣權限」，並導入硬體級金鑰加密儲存。
2. 一鍵套用風控模板
未來上線後，使用者只需選擇保守／穩健／積極三種風控檔位，即可自動套用 80/10/10 資金池與體質自適應引擎。
3. 專屬雲端常駐排程
無需使用者自備電腦或設定程式環境，由雲端隔離容器執行 24 小時自動盯盤與交易帳務勾稽對帳。
